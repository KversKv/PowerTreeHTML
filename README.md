# PowerTree — SoC 电源树离线可视化工具

> 纯静态网页, **双击 `index.html` 即用**, 无需安装任何东西, 无需联网。

## 一分钟上手

### 方式 A: 直接打开 (推荐)

```
双击 index.html
```

浏览器 (Chrome / Edge) 会自动打开, 第一次会弹**保密确认框**, 点"我已阅读并同意"即可进入。

### 方式 B: 本地服务器 (调试用)

```bash
python -m http.server 8765 --bind 127.0.0.1
# 然后访问 http://127.0.0.1:8765/index.html
```

## `index.html` 使用逻辑 (5 分钟掌握)

### 第 1 步: 看顶栏

```
[⚡ PowerTree] [板级|SoC域|表格|时序|看板]  [搜索框]  [模式▾][typ▾][配色▾][控制边][适应][展开][折叠][导出▾][导入][🔗][🌙][EN][E0 W0 I0][?][⌨][ⓘ][v0.3]
```

从左到右:
- **5 个视图切换** (快捷键 `1`~`5`)
- **搜索框** (快捷键 `/`)
- **模式下拉** — 切换 active / dvfs_lo / idle / suspend / off, 所有数字立刻重算
- **typ/max 切换** — 看典型值还是最大值
- **配色语义** — 按利用率 / 电压 / 电源域 / 类型 / 问题 / PMIC 着色
- **控制边** — 默认隐藏, 点开看 EN/PG/I2C/RESET 等虚线
- **导出** — SVG / PNG / CSV / Markdown / 打印
- **🌙 主题** — 深色/浅色
- **EN 语言** — 中英文切换
- **E/W/I 徽标** — 问题计数, 红色是错误必须处理
- **?** — 重放新手引导
- **ⓘ** — 关于/版本/联系人

### 第 2 步: 看主画布 (板级视图)

```
[VBAT 电池] ─→ [ORing] ─→ [eFuse] ─→ [BUCK_VSYS] ─→ [SoC 内置 PMIC 分组框]
                                              │
                                              ├─→ [BUCK_CPU] ─→ [VDD_CPU 负载]
                                              ├─→ [BUCK_DDR] ─→ [VDD_DDR 负载]
                                              ├─→ [LDO_PLL]  ─→ [VDD_CPU_PLL]
                                              └─→ ...
```

**你会看到**:
- **方框卡片** = BUCK / LDO / 负载 等抽象模块 (有名字/电压/电流/利用率条)
- **电路符号** = 电池 / 电阻 / 电容 / 电感 / 开关 / 保险丝 / 二极管 (标准电气符号, 无外框)
- **实线** = 电源连接 (线越粗电流越大, hover 看 net/电流/压降)
- **虚线** = 控制信号 (默认隐藏, 点顶栏"控制边"显示)
- **大框** = 分组 (板级 / PMIC / 电源域), 双击可折叠/展开
- **右上角 E/W/I 小圆点** = 该节点有问题

### 第 3 步: 点一个节点

点任意一个 BUCK 或 LDO, **右侧属性面板**会展开 9 个分区:

```
① 基本信息      id / 名称 / 型号 / 原理图页 / 备注
② 电气参数      Vin 范围 / Vout / imax / Iq / dropout / Rds_on
③ 计算结果      当前模式下 I_in / I_out / 利用率 / 末端电压 / 损耗 / 温升
④ 效率曲线      (如有 eff_ref) 标注当前工作点
⑤ 各模式电流    active/dvfs_lo/idle/suspend/off 横向对比
⑥ 供电链路      source → ... → 本节点 → 直连负载 (可点跳)
⑦ 时序信息      EN 源 / order / delay / ramp / PG
⑧ 相关问题      本节点命中的校核规则
⑨ 原始 JSON     可复制 (editor.html 中可编辑)
```

**这一屏就能回答 4 个问题**:
- 电从哪来 → 看 ⑥ 面包屑
- 供给了谁 → 看 ⑥ 直接下游
- 余量多少 → 看 ③ 利用率
- 有什么风险 → 看 ⑧ 问题

### 第 4 步: 看问题清单

右侧栏底部是**问题清单**面板, 按 E(红)/W(黄)/I(蓝) 分级列出全部校核结果。

**点击任意一条 → 自动跳到板级视图, 定位并高亮该节点**。

示例数据故意埋了 6 个问题, 你打开就能看到:
1. **E** `LDO_CAM_IN` Vin 越界 (上游 3.3~3.5V, 本节点只接受到 3.3V)
2. **E** `BUCK_DDR` 过流 (利用率 > 100%)
3. **W** `LDO_PLL` 压差不足 (Vin_min - Vout < dropout)
4. **E** `LDO_GPU` 时序违例 (order 早于上游)
5. **E** `LDO_SPARE` 孤立节点 (没任何边)
6. **E** `VDD_1V8` net 重名冲突 (1.8V 和 3.3V 都叫这个名)

### 第 5 步: 切视图

| 快捷键 | 视图 | 看什么 |
|---|---|---|
| `1` | 板级 | 主视图, 左 PMIC 右 Power Domain |
| `2` | SoC 域 | 数字电源域层级 + AON/Retention/ISO/RESET 标注 |
| `3` | 表格 | 所有 rail 排序/筛选/导出 CSV |
| `4` | 时序 | 上电/下电甘特图, 违例标红 |
| `5` | 看板 | Top-N 大电流 / 高利用率 / 问题分布 / 按域统计 |

## 常用操作速查

| 操作 | 方法 |
|---|---|
| 缩放 | 鼠标滚轮 |
| 平移 | 左键拖空白处 |
| 适应整图 | 按 `f` 或点顶栏"适应" |
| 框选多个 | `Shift` + 左键拖 |
| 聚焦某节点 | 双击节点 (显示 N 跳邻域) |
| 取消聚焦 | 双击空白处 |
| 看上下游 | 单击节点 → 自动高亮整条供电路径 |
| 折叠某分组 | 双击分组框 |
| 全部展开 | 按 `e` |
| 全部折叠 | 按 `c` |
| 搜索 | 按 `/` 输入关键词, 回车跳第一个 |
| 切换模式 | 顶栏下拉, 所有电流/利用率立刻重算 |
| 分享当前视角 | 点顶栏 🔗 复制链接 (含视图/模式/选中/缩放) |
| 导出图 | 顶栏"导出" → SVG / PNG (2x/4x) / 打印 |
| 导出数据 | 顶栏"导出" → CSV / Markdown |

## 想换成自己的电源树?

**只改一个文件**: `data/power_tree.data.js`

```
1. 参考 docs/schema.md 字段定义
2. 参考 docs/csv-template.csv 准备 Excel/CSV
3. 跑 python tools/csv2data.py 你的.csv data/power_tree.data.js
4. 跑 python tools/validate.py data/power_tree.data.js 校验
5. 刷新浏览器
```

或者打开 `editor.html` 在属性面板里直接改 JSON, 然后"导出 → data.js"下载替换。

## 遇到问题?

| 现象 | 解决办法 |
|---|---|
| 打开白屏 | F12 看 Console; 跑 `python tools/validate.py data/power_tree.data.js` |
| 看不到数据 | 是不是把 NDA 弹窗关了没点同意 |
| 图很乱 | 按 `f` 适应; 双击分组框折叠; 按 `c` 全部折叠 |
| 找不到节点 | 按 `/` 搜索 |
| 想看某个 rail 的来龙去脉 | 点它 → 右侧⑥看面包屑; 双击聚焦 |
| 数据改了不生效 | 浏览器强制刷新 `Ctrl+F5` |
