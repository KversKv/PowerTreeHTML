# Changelog

## v0.3 (2026-08-14)

### 首版发布

**核心功能**:
- 板级电源树视图 (ELK layered 布局, 左 PMIC / 右 Power Domain)
- SoC 内部电源域视图 (含 AON/Retention/ISO/RESET 标注)
- 表格视图 (排序/筛选/列显隐/CSV 导出)
- 时序视图 (上电/下电甘特图 + 违例标红)
- 汇总看板 (自绘 SVG, 无第三方图表库)

**计算引擎 (一期)**:
- 单级直连求和 (Iout_sum / 利用率)
- Vdrop 与末端电压
- LDO 热耗与温升
- 效率表双线性插值

**校核规则 (14 条全实现)**:
- E: Vin 越界 / 过流 / 时序违例 / 环路 / 无源可溯 / 孤立节点 / net 重名
- W: 余量不足 / LDO 压差 / LDO 热耗 / Vdrop 超容差 / 并联均流 / 多父未标注 / 模式不一致 / 无源应力
- I: 数据缺失

**通用交互**:
- 缩放/平移/Fit/框选/小地图
- 点击节点 → 9 分区属性面板
- 路径追溯 + 聚焦模式 (N 跳邻域)
- 搜索/过滤
- URL hash 状态持久化
- 首次使用 Tour 引导
- 中英文 / 深浅主题
- NDA 弹窗 + 水印 + 页脚保密声明

**导入导出**:
- 导入: .json / .data.js
- 导出: SVG / PNG (2x/4x) / CSV (BOM) / Markdown / JSON / data.js / 打印

**数据**:
- 示例 ≥45 节点, 覆盖全部 17 种类型
- 5 种功耗模式 + 级联链 + 并联组 + 跨接 + 控制边
- 故意埋 6 个可检出问题 (Vin 越界 / 过流 / 压差 / 时序 / 孤立 / net 重名)
- 2 个器件的效率表 (每器件 ≥2 工况, 1mA step)

**工具**:
- `tools/pack.py`: 打包单文件 HTML
- `tools/csv2data.py`: CSV → data.js
- `tools/validate.py`: CI 校验

**已知限制**:
- 一期不做跨级功率汇总 / 续航估算 (接口预留)
- Web Worker 在 file:// 下降级为主线程布局
